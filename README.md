# ChatLingo 反馈 · Feedback

ChatLingo 是一款 AI 驱动的对话式语言学习应用——与 AI 伙伴实时对话练习口语，
即时纠错、CEFR 水平评估、每周学习计划、词汇复习与成就统计。

> 本仓库**只用于问题反馈与功能建议**，不包含应用源码。

## 下载

👉 **<https://chatlingo.geniux.top>**（Android 版；iOS 版 TestFlight 筹备中）

## 反馈问题

点击上方 **Issues → New issue** 提交。

为了更快定位问题，请尽量附上：

| 信息 | 示例 |
|---|---|
| 问题描述 | 长按录音后没有转写结果 |
| 复现步骤 | 1. 打开场景对话 2. 长按麦克风 3. 松手 |
| 期望结果 vs 实际结果 | 期望出现文字 / 实际无反应 |
| App 版本 | v0.1.0（「我的」页底部可见） |
| 设备与系统 | 小米 13 / Android 14 |

## 反馈类型

- 🐛 **Bug 报告** — 应用崩溃、功能异常、显示错乱
- 💡 **功能建议** — 想要的新场景、新功能、体验改进
- ⚠️ **内容问题** — AI 回复不当、纠错错误
- ❓ **使用疑问** — 安装、登录、使用相关问题
